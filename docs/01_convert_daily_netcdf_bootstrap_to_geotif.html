Sea Ice Data: netCDF to GeoTIFF Conversion

This script converts daily National Snow and Ice Data Center (NSIDC) sea ice concentration files from their native netCDF format (.nc) to GeoTIFF format (.tif), using the packages ncdf4, terra, and progress.

For each file, the raster is loaded, assigned a coordinate reference system if one is not already defined, and has flagged (not ice concentration) values set to NA before being converted to GeoTIFF. A progress bar tracks progress through the batch, and any files that fail to convert are recorded rather than halting the run.

Work flow

This is the second script in a four-script workflow. The raw data are downloaded with 00_download_seaice_data_from_nsidc.Rmd script, converted from the native netCDF format to GeoTIFFs with the current 01_convert_netcdf_to_geotif.Rmd, then extracted from the pixels of interest using 02_extract_specEider_winterice_bootstrap_sic_geotif.Rmd, and finally summarized into annual sea ice variables with 03_summarize_daily_min_bs3_sic.Rmd.

Inputs

  • Input directory: a directory of daily netCDF files downloaded by the companion download script, named NSIDC0079_SEAICE_PS_N25km_[YYYYMMDD]_v4.0.nc.
  • Output directory: the destination folder for converted GeoTIFF files, created automatically if it does not already exist.
  • Coordinate reference system: EPSG:3411 (NSIDC Sea Ice Polar Stereographic North), assigned only if a file’s raster does not already have a CRS defined.
  • Flag values: raw sea ice concentration values above 1000 (per NSIDC metadata, flag values of 1100 and 1200 indicate land and missing data, respectively) are set to NA.

The input directory is specified as data/sourced_data/nsidc_sic_v4/sic_raw_netcdf/sic_netcdf_19921101_19921105 and the output directory as data/sourced_data/nsidc_sic_v4/sic_geotif. A total of 5 netCDF file(s) were found in the input directory and will be processed below.

Conversion loop

All netCDF files in the input directory (filtered to nc_files above) are processed in a loop: each is loaded as a raster with terra::rast(), assigned a coordinate reference system if missing, has flagged values set to NA, and is written out as a GeoTIFF with the same base filename.

# create progress bar
pb <- progress_bar$new(
  format = "  Converting [:bar] :percent | :current/:total | :filename", # pb layout
  total = length(nc_files), # total files
  clear = FALSE, # keep bar visible until loop finishes
  width = 60 # displayed bar width
)

error_log <- list() # collect any files that fail to convert, with the associated error message

for (f in nc_files) { # loop through each daily NetCDF file

  pb$tick(tokens = list(filename = basename(f))) # progress bar by 1 step each file

  tryCatch({
    base_name <- tools::file_path_sans_ext(basename(f)) # extract base name without extension
    out_file <- file.path(output_dir, paste0(base_name, ".tif")) # build output file name reusing base name with .tif extension
    r <- rast(f)  # load as raster, NB "varname" option not needed
    if (is.na(crs(r))) crs(r) <- "EPSG:3411"  # assign CRS (if not already defined in file)
    r[r > 1000] <- NA  # assign NA to values flagged with NA values (1100, 1200; as per metadata)
    writeRaster(r, out_file, overwrite = TRUE) # write to GeoTIFF, file format set by file name extension *.tif
  }, error = function(e) {
    error_log[[length(error_log) + 1]] <<- list(file = basename(f), message = conditionMessage(e))
  })
}

if (length(error_log) > 0) {
  cat(glue::glue("\n{length(error_log)} of {length(nc_files)} file(s) failed to convert:\n"))
  for (err in error_log) {
    cat(glue::glue("  {err$file}: {err$message}\n"))
  }
} else {
  cat(glue::glue("\nAll {length(nc_files)} file(s) converted successfully.\n"))
}
