Update 2026

Bootstrap sea ice concentrations from Nimbus-7 SMMR and DMSP SSM/I satellites ended in December 2025 when the Department of Defense stopped processing and delivering satellite imagery data to the NSIDC/public, as per this NSIDC notice: https://nsidc.org/data/user-resources/data-announcements/user-notice-ssmis-data-processing-end-30-june-2025

Unless the DOD re-establishes that data stream, another source of sea ice concentration data will be required for assess sea ice cover data in the spectacled eider sea ice index area. The best alternative is likely NOAA/NSIDC Climate Data Record of Passive Microwave Sea Ice Concentration, Version 6 (https://nsidc.org/data/g02202/versions/6).

Sea Ice Data: Download

Sea ice concentration (sic) data are from the Scanning Multichannel Microwave Radiometer (SMMR) on the Nimbus-7 satellite and the Special Sensor Microwave/Imager (SSM/I) sensors on the Defense Meteorological Satellite Program’s (DMSP) -F8, -F11, and -F13 satellites (Dataset: “Bootstrap Sea Ice Concentrations from Nimbus-7 SMMR and DMSP SSM/I-SSMIS V004.”

Data were generated using the Advanced Microwave Scanning Radiometer - Earth Observing System (AMSR-E) Bootstrap Algorithm with daily varying tie-points and gridded on the SSM/I polar stereographic grid (25 x 25 km grid cells; northern hemisphere spatial reference system EPSG:3411). Data coverage began on 01 November 1978. The current version of the bootstrap algorithm is version 4.0, which was released in November 2023.

Data also are available for manual download at: https://search.earthdata.nasa.gov/ (see end of this markdown doc) or programmatically downloaded from NASA’s cloud-hosted archive (see below).

Data overview and links to documentation, including a user’s guide, are at: https://nsidc.org/data/nsidc-0079/versions/4.

Version 4.0 uses the netCDF file format (.nc), which is a change from the previous versions that used the binary format (.bin). The netCDF format contains all metadata and can be read into Program R and examined with functions from the package “ncdf4”, which is not used here.

Data files use the naming convention: NSIDC0079_SEAICE_PS_N25km_[date as YYYYmmdd]_v4.0.nc.

This Program R script downloads data from data.nsidc.earthdatacloud.nasa.gov between two specified dates (start_date, end_date) and is setup to download only for the months (November, December, January, February, March, and April), as specified in the vector winter_months.

This script uses a project-based directory structure with file path *data/sourced_data/nsidc_sic_v4/sic_raw_netcdf/sic_netcdf_[YYYYmmdd start date]_[YYYYmmdd end date]/* as the download directory.

Work flow

This is the first script in a four-script workflow. The raw data are downloaded here with this 00_download_seaice_data_from_nsidc.Rmd script, converted from the native netCDF format to GeoTIFFs with 01_convert_netcdf_to_geotif.Rmd, extracted from the pixels of interest using 02_extract_specEider_winterice_bootstrap_sic_geotif.Rmd, and summarized into annual sea ice variables with 03_summarize_daily_min_bs3_sic.Rmd.

Data download

This code queries NASA’s Common Metadata Repository (CMR) for the matching daily granules (i.e., daily data sets). It searches the relevant collection for the specified date range, filters to northern-hemisphere files (using the *N25km* of the file name), and excludes monthly-average summary files that CMR also returns.

Each matching daily file is downloaded via curl, authenticated using either an Earthdata Login (EDL) bearer token or a .netrc file containing Earthdata Login credentials.

For each download attempt, the file is checked (file size and content) to id cases where authentication failed and an error page was saved instead of the actual data file. The list of dates actually returned by CMR is compared to the list of dates requested, to id cases where NSIDC has not yet published data for part of the requested range (i.e., recent data - there is usually a several month lag, with data releases several times per year).

The R console displays messages indicating a successful download, a failed download, a failed validation check, a date with no available data, or if the file already exists in the directory.

# Download loop ####

files_expected <- nrow(granules)
results <- vector("character", files_expected)
validation_notes <- vector("character", files_expected)

for (i in seq_len(files_expected)) {
  
  filename <- granules$filename[i]
  url      <- granules$url[i]
  destfile <- file.path(save_dir, filename)
  
  if (file_exists(destfile) && file_info(destfile)$size > 0) {
    v <- validate_download(destfile, min_expected_bytes, max_expected_bytes)
    if (v$ok) {
      cat(glue("⏩ Already exists (valid): {filename}\n"))
      results[i] <- "exists_valid"
    } else {
      cat(glue("⚠️  Already exists but FAILED validation ({v$reason}): {filename}\n"))
      results[i] <- "exists_invalid"
    }
    validation_notes[i] <- v$reason
    next
  }
  
  if (nzchar(edl_token)) {
    curl_cmd <- glue(
      "curl -L -H \"Authorization: Bearer {edl_token}\" -o \"{destfile}\" \"{url}\""
    )
  } else {
    curl_cmd <- glue(
      "curl --ssl-no-revoke --netrc-file \"{netrc_path}\" -L -c cookies.txt -b cookies.txt -o \"{destfile}\" \"{url}\""
    )
  }
  
  result <- system(curl_cmd)
  v <- validate_download(destfile, min_expected_bytes, max_expected_bytes)
  validation_notes[i] <- v$reason
  
  if (v$ok) {
    cat(glue("Downloaded & validated: {filename}\n"))
    results[i] <- "downloaded_valid"
  } else {
    cat(glue("⚠️  Downloaded but FAILED validation ({v$reason}): {filename}\n"))
    results[i] <- "downloaded_invalid"
  }
  
  Sys.sleep(2)
}
