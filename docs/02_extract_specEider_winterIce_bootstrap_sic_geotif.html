Sea Ice Data: Extraction

This script extracts sea ice concentration (sic) data from the 16 pixels (each 25 km x 25 km) in the northern Bering Sea identified in Petersen and Douglas (2004) as spectacled eider winter range, based on satellite transmitter locations from the 1990s. These 16 pixels are used as an index of sea ice conditions across the broader area of the Bering Sea used by spectacled eiders, following Petersen and Douglas (2004), Flint et al. (2016), Christie et al. (2018), Dunham et al. (2021), and Friendly et al. (2025).

The output is a daily time series of sic (percent cover, 0 to 100) at each of the 16 pixels, for each winter (01 Nov to 30 Apr) day.

This script was adapted from code posted by A. Fischbach, modified by G. Durner in 2020, and updated by D. Rizzolo in 2020.

Data are SMMR and SSM/I Passive Microwave SIC from the Bootstrap Algorithm, version 4.0 (released November 2023):

This script processes one winter of data (most recently available) and appends that new data to the existing data set spanning all winters processed to date.

Work flow

This is the third script in a four-script workflow. The raw data are downloaded here with this 00_download_seaice_data_from_nsidc.Rmd script, converted from the native netCDF format to GeoTIFFs with 01_convert_netcdf_to_geotif.Rmd, then extracted from the pixels of interest using the current 02_extract_specEider_winterice_bootstrap_sic_geotif.Rmd script, and finally summarized into annual sea ice variables with 03_summarize_daily_min_bs3_sic.Rmd.

Inputs

  • Pixel coordinate reference file: library/specEider_winter_pixel_samples_xy_geo_SAVE.csv - longitude/latitude (WGS84) coordinates of the 16 spectacled eider winter-range pixels.
  • Input directory of daily GeoTIFFs: data/sourced_data/nsidc_sic_v4/sic_geotif/ (the same directory produced as output by 01_convert_netcdf_to_geotif.Rmd) - one file per day, named NSIDC0079_SEAICE_PS_N25km_[YYYYMMDD]_v4.0.tif. The file list is filtered to .tif files only, to avoid picking up any sidecar/auxiliary files that may be written alongside the GeoTIFFs. The date and month are parsed from fixed character positions within this filename (positions 27-34 for the full date, 31-32 for the month), so input files must follow this exact naming convention and length for those extractions to return the correct characters.
  • Existing cumulative output file (read in during the final append step): output/sic_beringSea_16pixels/nsidc_sic_summary_v4/sic_bootstrapv4_16pixels_01Nov-30Apr_1992-2024.csv - the previously compiled multi-year record that this script appends to.

Spatial data references used in this script:

  • EPSG:3411 - NSIDC Sea Ice Polar Stereographic North (the projection of the sea ice GeoTIFFs; assigned during conversion in 01_convert_netcdf_to_geotif.Rmd)
  • EPSG:4326 - WGS 84 Geographic (the projection of the pixel coordinate reference file)
# spatial data references used here:
#* EPSG:3411: NSIDC Sea Ice Polar Stereographic North
#* EPSG:4326: WGS 84 Geographic

# make Sea Ice Concentration (SIC) grid cell reference coordinates spatial with st_as_sf from package sf and reproject to same CRS as sea ice data
eider16.geo <- read.csv("library/specEider_winter_pixel_samples_xy_geo_SAVE.csv") # Read CSV into a regular data frame
eider16.sf <- st_as_sf(eider16.geo, coords = c("lon", "lat"), crs = 4326) # Convert to an sf object with WGS84 coordinates (EPSG:4326)
eider16.ps <- st_transform(eider16.sf, crs = 3411) # Reproject to NSIDC Sea Ice Polar Stereographic North (EPSG:3411)

Extraction

For each daily GeoTIFF in the input directory, this script loads the raster, extracts the sic value at each of the 16 reprojected pixel locations, and appends the result (with date, projected x/y coordinates, and original lon/lat) to a running list of daily data frames. Only files whose parsed month falls within the winter processing window are extracted; all others are skipped. Any file that fails to load or extract is logged to error_log and skipped, rather than stopping the whole run.

tif.list <- as.list(list.files(path = geotif_dir, pattern = "\\.tif$"))
eider_list <- list() # Initialize list to collect daily data frames
# code applied to all version 4 data from period of spectacled eider mark-resight project: 01 Nov 1992 - 31 Dec 2024 (most recent available data as of Sept 2025)
# subsequently, apply to each newly released year of data

# create progress bar
pb <- progress_bar$new(
  format = "  Converting [:bar] :percent | :current/:total | :filename", # pb layout
  total = length(tif.list), # total files
  clear = FALSE, # keep bar visible until loop finishes
  width = 60 # displayed bar width
)

error_log <- list() # collect any files that fail to load/extract, with the associated error message

# loop through directory of geotif files
for (f in tif.list) {
  pb$tick(tokens = list(filename = f)) # progress bar by 1 step each file
  month <- as.numeric(substr(f, 31, 32))  # assign month from file name (example: "NSIDC0079_SEAICE_PS_N25km_20211114_v4.0.tif")
  # Process only Nov–Apr
  if (month >= 11 || month <= 4) {
    tryCatch({
      # load raster using terra
      filename <- file.path(geotif_dir, f) # assign file name with path
      rr <- terra::rast(filename)
      # extract sea ice values at point locations for 16 eider pixels of interest
      values <- terra::extract(rr, vect(eider16.ps))[,2]  # second column is the ice value
      # get coordinates from sf object
      coords <- sf::st_coordinates(eider16.ps)
      colnames(coords) <- c("x", "y") # rename columns upper- to lowercase
      # create data frame
      eider16p <- eider16.ps %>%
        st_drop_geometry() %>% # remove the geometry column of the sf object
        # add column for:
        mutate(bs_sic_prop = values, # sea ice concentration 
               sicDate = substr(f, 27, 34), # extract date from file name, positions 3 to 10
               x = coords[, "x"], # EPSG 3411 x values
               y = coords[, "y"]
               ) %>% # EPSG 3411 y values
        # join the original lat/lon columns from eider16.geo by row index
        dplyr::bind_cols(
          eider16.geo %>% dplyr::select(lon, lat)
        )
      # append to list
      eider_list[[length(eider_list) + 1]] <- eider16p # append daily values
    }, error = function(e) {
      error_log[[length(error_log) + 1]] <<- list(file = f, message = conditionMessage(e))
    })
  }
}

if (length(error_log) > 0) {
  cat(glue::glue("\n{length(error_log)} file(s) failed to extract:\n"))
  for (err in error_log) {
    cat(glue::glue("  {err$file}: {err$message}\n"))
  }
} else {
  cat(glue::glue("\nAll {length(eider_list)} file(s) extracted without errors.\n"))
}

Outputs

Running this script produces the following:

  • eider16p: an in-session data frame with one row per pixel per successfully processed day, including lon, lat, projected x/y coordinates (EPSG:3411), bs_sic_prop (sea ice concentration, percent), and sicDate (date parsed from the source filename).
  • error_log: a list of any GeoTIFFs within the winter processing window that failed to load or extract, each with the associated error message, so failures can be investigated without re-running the entire batch.
  • A single-winter CSV, output/sic_beringSea_16pixels/[year]_sic_bootstrapv4_16pixels_01Nov-30Apr.csv.
  • all_previous: the previously saved cumulative multi-year record, read back in for the append step.
  • bind: the combined data frame (all_previous + eider16p), optionally de-duplicated if the commented-out duplicate-check lines are enabled.
  • An updated cumulative CSV: output/sic_beringSea_16pixels/nsidc_sic_summary_v4/sic_bootstrapv4_16pixels_01Nov-30Apr_1992-[year].csv, replacing the prior cumulative file with one extended through the newly processed winter.
